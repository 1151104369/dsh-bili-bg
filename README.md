# dsh-bili-bg

把 **B 站视频当作可控的全屏背景**，边工作边看。基于 DSH 的视频皮肤思路扩展而来，是独立插件（不依赖 `dsh-video-skin`）。

## 功能

- **输入 BV 号 / 粘贴 bilibili 链接** → 当背景播放；也支持热门 / 排行榜 / **舞蹈区** / **舞蹈UP主** / **首页推荐**（需登录）队列
- **B 站账号登录（二维码扫码）**：控制面板「账号」区点「二维码登录」→ 出现二维码 → 手机上扫码
  确认 → 面板显示**头像 + 昵称**，可「退出登录」；二维码过期自动刷新（轮询 2s）
- **账号首页 / 推荐列表**：登录后切换来源到「首页推荐」，拉取账号推荐 feed（WBI 签名）点条目即播
- **悬浮胶囊**（可拖动、可展开/收回）：
  - 展开后是 `▶/⏸` 播放暂停、`⏭` 下一支、`清` 清屏、`专` 专注隐藏/恢复、`⚙` 设置
  - 点击胶囊展开/收回；拖动（>3px）移动并记住位置
- **控制面板（顶部常驻信息 + 标签页 + 可拖动）**：
  - **账号与视频详情常驻顶部**：未登录时左侧「未登录」、右侧「扫码登录」；登录后左侧头像+昵称、
    右侧「退出登录」。**点视频详情可在系统浏览器打开该视频**
  - 标签页：「播放 / 列表 / 下载 / 设置」，底部状态行常驻不滚动；**面板固定高度**，
    切换标签页长度一致，只有内容区一个滚动条（列表不再套内层滚动条）
  - **拖标题栏可移动面板**，位置会记住（重启恢复）；关闭按钮不受拖动影响
  - 播放页：暂停/上一支/下一支在**进度条上方**；进度与音量两条滑动条相邻，
    音量行右侧只放**喇叭图标**的静音键（无文字）
  - 设置页：显示方式、背景、界面不透明度、蒙版浓度，以及**专注隐藏**和**清屏**按钮
  - 扫码登录用浮层展示二维码，不撑高顶部
  - **进度条**（可拖动跳转，显示 `当前 / 总时长`）
  - **倍速**（0.5x ~ 2x）
  - **列表连播**（`🔁 列表连播`：放完当前自动播列表下一支）与 **单曲循环**（`🔂 单曲循环`：
    放完从头再播）两个开关，**互斥**（开一个会自动关另一个）；都与高清/720p 模式配合工作。
    - 高清（MSE）下个别内核不派发 `ended`，可能是单曲循环/连播不生效的原因；内置**结尾看门狗**
      每秒兜底检测（贴近结尾且需手动收尾时触发一次幂等收尾），720p 原生循环失效时也会自动回 0 续播。
  - **首页推荐 / 热门 / 排行榜 / 舞蹈区 / 舞蹈UP主**切换、**刷新列表**（重新拉取当前来源）
    - **舞蹈UP主**：专挑「完整舞蹈投稿」——按 宅舞/翻跳/街舞 搜索高点击结果，只保留**时长 ≥45s 且 ≤20min**、
      分区名含「舞」的视频，**每个 UP主最多 2 条**（避免整屏同一人）；搜索接口风控时自动用舞蹈区排行榜按同样规则兜底。
    - 默认来源：**已登录 → 首页推荐；未登录 → 热门**（未登录点首页推荐会提示需登录）
    - 手动切换过来源后记住你的选择，不再自动改；退出登录时若停在首页推荐会自动回落热门
  - 显示方式：**完整**（按宽度靠顶、不裁切、下方留空）/ **铺满**
  - 背景：**保留**（透出 dsh-video-skin / 主题背景）/ **留空**
  - 界面不透明度、蒙版浓度
- **清屏**：只隐藏中间会话内容区，左侧会话/任务列表保持可见可点；点左侧任意会话会自动恢复并切换
- **专注模式**：隐藏视频画面继续工作（面板按钮或胶囊「专」一键切换）；重启后保持上次状态
- **下载当前视频（跟随当前播放画质）**：控制面板里一键把正在播的视频存成 mp4；点击后弹 **Windows「另存为」对话框**
  （默认目录=注册表 KnownFolder 解析的系统下载目录，如 `F:\Downloads`；默认文件名=标题-BV号-清晰度.mp4），
  你确认存在哪里就下到哪里，取消则不下载；弹不出对话框时回退自动保存到 `Downloads/DSH-B站背景/`
  （系统下载目录不存在时退 `$DSH_HOME/downloads`）。流式写 .part 原子落地，面板显示
  百分比 / 已下载·总量 / 实时速度；**下载中按钮变「✕ 取消下载」**，点了立即中止并清理半成品
  - **按当前播放画质下载**：720p 模式 → 720p 单文件；高清模式 → 对应清晰度的 DASH 分轨（如 1080p）。
  - 有 **ffmpeg** 时自动 `-c copy` 合轨成单个 mp4（`DSH_BILI_FFMPEG` 可指定路径）；没有 ffmpeg 时
    分别保存**视频轨 + 音频轨**两个文件（画质不降级，面板会提示）。
  - **ffmpeg 一键下载**：面板下载区会显示 ffmpeg 状态，未检测到时点「⬇ 下载 ffmpeg」自动下载安装
    单文件版（默认走 npmmirror 的 `@ffmpeg-installer` 平台包，约 22MB；也支持手动下载后放到
    `$DSH_HOME/dsh-bili-bg-bin/ffmpeg.exe`，或用 `DSH_BILI_FFMPEG` 指定路径）。装好后高清下载自动合轨。
- **记住播放进度**：每 5 秒 + 暂停/关闭页面时保存；重启后**播放中退出**自动接着播
  （无手势时浏览器会静音，点 🔊 开声音），**暂停时退出**则恢复那一支到原进度但保持暂停，
  点播放继续——不会丢视频、不用回列表重选
- **登录后高清（1080p+）**：控制面板「高清（1080p+）」开关（快捷键/胶囊「专」下方）。
  - 打开后带登录 Cookie 走 DASH 分轨（qn=80/112/116，fnval=4048），在**同一个 `<video>`**
    上用 MSE 挂 video/audio 两个 SourceBuffer 混流，浏览器统一时间轴保证音画同步
    （各轨先 append 自己的 init 段，再按时间序 append 媒体分片）。
  - 可选的**分轨清晰度**按钮（1080P / 720P / 480P / 360P…）。B 站同一清晰度会返回
    avc1/hvc1/av01 多条编码，界面**按高度去重**，并自动优选浏览器 MSE 支持、H.264 优先的编码。
  - **切换高清/清晰度会保住当前进度**（不会从头播）；播放结束自动回开头续播（背景不断流）。
  - 拖动进度条：拖动中只更新文案，**松手才做一次两轨对称 seek**；seek 地址由分轨的 `sidx`
    索引精确算出字节偏移，远距离/来回拖动都能落到目标（真实浏览器实测 600/1800/300/7155/60/3600s
    全部命中）。append 以**完整 fragment（moof+mdat）**为单位，避免停在 mdat 中间导致
    `MEDIA_ERR_DECODE`；只预缓冲前方 90s、播放点后保留 30s，长时间播放不会撑爆 MSE 配额。
  - **画质降级开关**：关闭「高清」立即回到 720p 单文件；MSE 不可用/失败/超时（20s）时宿主自动回退
    720p 单文件，**绝不白屏、也不会停在“播放中”却没画面**（等 MSE 真正就绪才显示“高清播放中”）。
    回退只影响**当前视频**（标签显示「本视频回退 720p」），**高清偏好仍会保留并持久化**，
    重启后仍会尝试高清，不会因为某个视频不支持就悄悄变回非高清。
  - **切换速度**：高清用 DASH（init 仅 ~1KB）所以切换快；**切回 720p 会在高清播放时后台预热**
    （隐藏 `<video>` + /media 短时缓存），实测切回约 0.3s（未预热时长达 4~8s）。
  - **状态不抢跑**：等第一帧真正可显示（readyState≥2 / loadeddata）才显示「高清播放中」并露出画面；
    单文件加载期间显示「加载 720p…」，出画面后才显示「正在播放」。
  - 720p **单文件冷启动**的长视频可能仍需几秒：B 站 mp4 把完整索引放在 `moov`，长视频可达 9MB
    （实测直连 CDN 也约 5.8s），这是单文件格式本身的成本；用高清（DASH）则只需小 init 段。
  - **不会误静音**：高清等 MSE 就绪后才开播；只有浏览器「自动播放策略」拦截（NotAllowedError）
    才退回静音，源未就绪之类的失败绝不自动静音。
  - init 探针只读约定字节数（够数即 cancel）：即使 CDN 忽略 `Range`、返回整条数 GB 流，也不会
    卡到 20s 超时；直连 mediaBase 6s 无响应会自动改用同源相对地址。
  - 未登录开高清会提示「需登录」；服务端拿不到分轨也会自动回退并明确告知。
- 快捷键 `Ctrl+Shift+B` 开关面板
- **分P**：多 P 视频在**顶部视频信息下方**显示分P选择器（常驻、不随标签页滚动），点某 P 即切（换 cid 重解析，从头播）；当前分P会记到状态文件，重启后恢复；下载也跟随当前 P
- **弹幕**：`💬 弹幕` 开关，在视频上渲染随播放进度滚动的氛围弹幕（canvas 浮层贴合**视频实际显示区**、字号按画面比例；获取/渲染任何失败自动隐藏，绝不干扰播放）。设置页可调：**弹幕字号 / 不透明度 / 速度 / 显示区域**（均持久化）。**只在视频真正出画面并播放时绘制**（缓冲/暂停时冻结，切视频不会出现弹幕先于画面）
- **纯氛围静音墙纸**：设置页 `🖼 静音墙纸` 一键切到「静音 + 悬浮胶囊收起」的无感后台播放；**关闭时还原开启前的静音与胶囊状态**（非单向），重启后保持

## 接入方式

作为本地 bundle 挂到 desktop profile：

- `C:\Users\11511\.dsh\profiles\desktop\package.json`
  - `dependencies` 里加 `"@local/dsh-bili-bg": "link:F:/GitHub/DSH/bundles/dsh-bili-bg"`
  - `dsh.profile.bundles` 里加 `"@local/dsh-bili-bg"`
- 在 profile 的 `node_modules/@local/` 下建 Junction 指向本目录

宿主用 `webserver/index-inject` 注入样式与脚本；**桌面壳启动时一次性收集注入表**，所以插件相关改动需要重启 DSH 生效。

## 已知限制

- 高清需要**登录态**：未登录或该清晰度拿不到分轨时自动回退 720p 单文件（面板会提示）。
  4K / 杜比等更高级别既定级到 1080p，未做自适应码率（ABR）；长时间播放主要受网络抖动影响。
- MSE 取分轨走 fetch（跨源直连 127.0.0.1，带 `Range` 会触发 CORS 预检）。宿主 /media 路由必须
  正确应答 `OPTIONS`（204 + `Access-Control-Allow-Headers: Range`）并给 GET 加 `ACAO`；
  否则浏览器 fetch 会一直挂住，表现为「提示高清播放中但画面永远不出来」。已修复并有回归测试。
- MSE append 必须按**完整 fragment**（moof+mdat）提交。若把字节流切在 mdat 中间就 append 新的
  moof，浏览器解析器会 `MEDIA_ERR_DECODE`（真机复现过）。`runtime/dash.js` 里的 box 切分器负责
  保证这一点；seek 时丢弃未组装完的半截 fragment。
- 高清诊断：最近一次 MSE 状态/回退原因会写进 `state.hdDiag`（重启/排障可看）。
- 播放流经本地代理（带 `Referer` + `Range`）。Electron 的 `dsh-app://` 转发层会丢掉 `Content-Length`，会让 `<video>` 无法 seek，所以客户端优先**直连本机 HTTP**、失败再回退代理；MSE 取分轨也是直连 + 断线回退同源代理。
- 清屏依赖 `dsh-client-ui-layout` 的类名（匹配 `[class*="centerCol"]` / `[class*="sidebarCol"]`）。
- 仅面向 desktop profile（Electron 桌面壳）。
- **窗口大小不归本插件管**：DSH 桌面壳把主窗口尺寸硬编码在 `createWindow()`，且插件拿不到窗口控制
  （preload 沙箱 + IPC 白名单）。要做只能改 DSH 本体或加系统级工具，都不属于插件层，故不做。

## 状态文件

- `DSH_HOME/dsh-bili-bg.json`：记录来源（含手动选择标记）、上次 BV、音量/倍速/显示方式、
  专注模式、悬浮胶囊位置、播放进度（含是否在播/进度秒数）、**高清开关与清晰度偏好**、诊断信息。
- `$DSH_HOME/dsh-bili-bg-auth.json`：**登录凭据（Cookie）**，敏感凭证——写入时收紧文件权限
  （POSIX 0600；Windows 尽力 via `icacls` 且收紧后自检可读），日志/接口都**不回显**，面板只显示昵称/头像。

## 环境变量（可选）

- `DSH_BILI_DOWNLOAD_DIR`：覆盖下载保存根目录（默认走系统下载 KnownFolder）。
- `DSH_BILI_NO_DIALOG=1`：禁用「另存为」对话框，直接存默认目录（无头环境/自动化测试用）。
- `DSH_BILI_FFMPEG`：指定 ffmpeg 可执行文件路径（高清下载自动合轨用；不设则自动在 PATH/常见目录找）。
- `DSH_BILI_FFMPEG_URL`：覆盖 ffmpeg 一键下载地址（.gz 单文件或 .tgz npm 包均可）。
- `DSH_BILI_DEBUG=1`：B 站接口请求调试日志。
